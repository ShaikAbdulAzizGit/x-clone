# X (Twitter) Clone

A responsive front-end recreation of the X (formerly Twitter) interface, built with **HTML** and **Tailwind CSS**. The project focuses on recreating the familiar social-media layout while practicing responsive design, utility-first styling, hover effects, transitions, and UI components.

## 🔗 Live Demo

[View the live project](https://shaikabdulazizgit.github.io/x-clone/)

## 📂 Repository

[GitHub Repository](https://github.com/ShaikAbdulAzizGit/x-clone)

## ✨ Features

- **Fully responsive layout** designed to look good across mobile, tablet, and desktop screen sizes.
- **X-inspired interface** with a navigation sidebar, main feed, post composer, and supporting sidebar content.
- **Responsive navigation** that adapts its layout and visibility to different screen sizes.
- **Post feed UI** with profile details, text content, images, and video posts.
- **Hover effects** for navigation items, post actions, icons, and interactive-looking controls.
- **Smooth transitions and transforms** to make hover states feel more polished.
- **Consistent dark theme** inspired by X's interface.
- **Tailwind CSS utility classes** for layout, spacing, typography, colors, borders, sizing, and responsive styling.

## 🛠️ Built With

- **HTML5** – page structure and semantic elements.
- **Tailwind CSS** – responsive layouts, styling, hover states, and transitions.

## 📱 Responsive Design

The interface uses Tailwind CSS responsive utilities and a mobile-first approach to adapt the layout to different viewport sizes. Navigation and content sections adjust at responsive breakpoints to keep the experience usable on smaller screens and spacious on larger displays.

## 🎯 What I Practiced and Learned

Building this project helped me strengthen my foundational Tailwind CSS skills through practical implementation, including:

- Flexbox and layout positioning
- Responsive breakpoints and mobile-first design
- Spacing, sizing, and typography utilities
- Backgrounds, borders, and border radius
- Hover and focus state variants
- Transitions, transforms, and animation-related utilities
- Arbitrary values for more precise styling
- Reusable styling patterns and utility composition
- Organizing a multi-section interface with Tailwind CSS

I also worked on hover effects and UI-level interactions across navigation elements, icons, and post action controls. This project demonstrates how I can apply Tailwind CSS fundamentals to build and polish a responsive, real-world-inspired interface.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ShaikAbdulAzizGit/x-clone.git
   ```

2. Open the project folder:

   ```bash
   cd x-clone
   ```

3. Open `index.html` in your browser.

   If you use VS Code, you can also run the project with the Live Server extension.

## 📌 Project Scope

This is a **front-end UI clone** created for learning and practice. It recreates the visual layout and selected UI-level interactions of X; it is not an official X product and does not provide a connected social network backend, real user authentication, or live posting.
